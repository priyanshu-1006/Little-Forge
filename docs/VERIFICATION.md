## Current limits

The index is lexical rather than a full AST graph; it caps 2,500 files and an 8 MiB indexing read budget. Cold evaluation of Flask took about nine seconds on this machine; warm retrieval and larger repositories need further performance measurement. Conservative token units intentionally overestimate source tokens and are not reported provider usage.

Only local file workspaces and loopback TrueForge/MCP are supported. Writes are UTF-8 text, not binary/document workflows; ignore-policy file mutations are rejected. Dirty target editors must be saved. Native diff preview is supplied, while checkpoint undo is the supported restoration mechanism. Source transactions are journaled and conflict-checked, not a universal power-loss or hostile-writer filesystem transaction.

Project checks execute trusted repository code with user permissions. Their arbitrary side effects are outside edit undo. Source-side-effect detection is explicitly bounded/partial. Process cleanup reports whether it was confirmed. The harness may internally retry provider transport requests before the extension receives a terminal failure; the observed 503 fixture made three upstream requests.

Keep the local harness on localhost. Its state and model credentials are excluded from Git/VSIX. Old editor endpoints are revoked when a run changes; historical connector references in local TrueForge traces are not reusable active write authorizations.
